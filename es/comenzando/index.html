Comenzando con R Commander

The R Commander [1] [2] provides a graphical user interface («GUI») to the open-source R statistical computing environment [3]. This manual is a brief, basic introduction to the R Commander; for more extensive documentation, see [2], which has a website at https://www.john-fox.ca/RCommander/.

R Commander [1] [2] proporciona una interfaz gráfica de usuario («GUI») para el entorno estadístico de código abierto R [3]. Este manual es una introducción breve y básica a R Commander; para obtener una documentación más extensa, consulte [2], que cuenta con un sitio web en https://www.john-fox.ca/RCommander/.

R is a command-driven system, and new users often find learning R challenging. This is particularly true of those who are new to statistical methods, such as students in basic-statistics courses. By providing a point-and-click interface to R, the R Commander allows these users to focus on statistical methods rather than on remembering and formulating R commands. Moreover, by rendering the generated commands visible to users, the R Commander has the potential for easing the transition to writing R commands, at least for some users. The R Commander, however, accesses only a small fraction of the capabilities of R and the literally thousands of R packages contributed by users to the Comprehensive R Archive Network (CRAN). The R Commander is itself extensible through plug-in packages, and many such plug-ins are now available on CRAN (see Section Using R Commander Plug-ins).

R es un sistema basado en comandos, y a los nuevos usuarios a menudo les resulta difícil aprender R. Esto es especialmente cierto en el caso de quienes se inician en los métodos estadísticos, como los estudiantes de cursos básicos de estadística. Al proporcionar una interfaz de apuntar y hacer clic (point-and-click) para R, el R Commander permite a estos usuarios concentrarse en los métodos estadísticos en lugar de tener que recordar y formular comandos de R. Además, al hacer visibles los comandos generados para los usuarios, el R Commander tiene el potencial de facilitar la transición hacia la escritura de comandos de R, al menos para algunos usuarios. Sin embargo, el R Commander accede solo a una pequeña fracción de las capacidades de R y de los literalmente miles de paquetes de R aportados por la comunidad de usuarios al Comprehensive R Archive Network (CRAN). El R Commander es extendible en sí mismo mediante paquetes de complementos (plug-ins), y muchos de estos plug-ins están ahora disponibles en el CRAN (consulte la Sección Uso de complementos (plug-ins) de R Commander).

This document directly describes the use of the R Commander under the Windows version of R. There are small differences in the appearance and use of the R Commander under macOS and on Linux and Unix systems. Information about installing the R Commander on these platforms is available by following the link to the installation notes at the R Commander web page https://www.john-fox.ca/RCommander/

Este documento describe directamente el uso del R Commander bajo la versión de Windows de R. Existen pequeñas diferencias en el aspecto y uso del R Commander bajo macOS y en sistemas Linux y Unix. La información sobre la instalación del R Commander en estas plataformas está disponible siguiendo el enlace a las notas de instalación en la página web del R Commander https://www.john-fox.ca/RCommander/

I use the following typographical conventions in this document: Names of software, such as Windows, R, the Rcmdr package, and the R Commander, are set in boldface type. The names of GUI elements such as menus, menu items, windows, and dialog boxes, are set in italic type. Variable names, names of data sets, and R commands are set in a typewriter font.

Utilizo las siguientes convenciones tipográficas en este documento: los nombres de software, como Windows, R, el paquete Rcmdr y el R Commander, se muestran en letra negrita. Los nombres de los elementos de la interfaz gráfica (GUI), como menús, elementos de menú, ventanas y cuadros de diálogo, se muestran en letra cursiva. Los nombres de variables, nombres de conjuntos de datos y comandos de R se muestran en fuente mecanográfica.
